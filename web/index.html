Industrial Architecture & Signal Path

5-Tier Architecture
1
Mitsubishi Electric Q03UDECPU

Industrial PLC controller running autonomous ladder scan. Built-in 100BASE-TX Ethernet port configured at 192.168.3.39:5010. Serves MC Protocol Type 3E binary frames.

2
Host Gateway Daemon (Windows Laptop)

Python 3 gateway.py issuing read-only command 0x0401 (Batch Read Bit Units). Enforces zero writes. Encapsulates telemetry into newline-delimited JSON over USB COM9.

3
Edge Microcontroller Bridge (NodeMCU ESP8266)

Arduino C++ firmware plc_monitor.ino reading serial at 115200 baud. Asynchronous Wi-Fi connection with TLS 1.2 client publishing to EMQX Cloud Serverless.

4
Cloud MQTT Broker (EMQX Cloud)

Secure managed broker publishing on plcmon/plc-gw-01/telemetry. Dedicated read-only subscriber account prevents write injection.

5
Supervisory Web Client (GitHub Pages)

Static zero-dependency HTML5/CSS/JavaScript console subscribed over secure WebSockets (wss://). Validates payload schemas and displays ISA-101 HMI.

Industrial Security & Public Client Policy:

Non-sensitive configuration (URL, username, topic) is saved to localStorage. Passwords are never saved to storage. Website users must utilize dedicated broker accounts configured with strictly limited, read-only topic permissions (Subscribe only to plcmon/plc-gw-01/#) with zero publish permissions.
