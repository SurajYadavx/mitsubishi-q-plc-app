Industrial Architecture & Signal Flow

5-Tier Architecture
1
Mitsubishi Electric Q03UDECPU

Industrial PLC controller running autonomous ladder scan. Built-in 100BASE-TX Ethernet port configured at 192.168.3.39:5010. Serves MC Protocol Type 3E binary frames.

2
Host Gateway Daemon (Windows Laptop)

Python 3 gateway.py issuing read-only command 0x0401 (Batch Read Bit Units). Enforces zero writes. Encapsulates telemetry into newline-delimited JSON over USB COM9.

3
Edge Microcontroller Bridge (NodeMCU ESP8266)

Arduino C++ firmware plc_monitor.ino reading serial at 115200 baud. Asynchronous Wi-Fi connection with TLS 1.2 client publishing to HiveMQ Cloud.

4
Cloud MQTT Broker (HiveMQ Cloud)

Secure managed broker publishing on plcmon/plc-gw-01/telemetry. Read-only subscriber ACL prevents browser write injection.

5
Supervisory Web Client (GitHub Pages)

Zero-dependency HTML5/CSS/JavaScript application subscribed over secure WebSockets (wss://). Validates payload schemas, monotonic sequence numbers, and displays ISA-101 HMI.

Industrial Security & Public Client Policy:

Non-sensitive configuration (URL, username, topic) is saved to localStorage for operator convenience. Passwords are never saved to storage and exist only in transient browser memory during connection.

Public-Client Constraint: In browser-based web applications, client-side MQTT credentials cannot be kept secret from inspection. Website users must utilize dedicated broker accounts configured with strictly limited, read-only topic permissions (e.g. Subscribe only to plcmon/plc-gw-01/#) with zero publish or broker administrative access.
